# AI Skills

A collection of reusable AI skills designed to improve the way AI assists
with software development, frontend design, and other technical workflows.

The goal of this repository is to provide practical, opinionated guidelines
that encourage better decisions instead of relying on generic AI-generated
patterns.

## Skills

### Professional Frontend Design

A frontend design skill focused on creating interfaces that are:

- Minimal
- Clean
- Sharp
- Smooth
- Professional
- Responsive
- Visually intentional

It focuses on visual hierarchy, spacing, typography, color systems,
component design, interaction, animation, accessibility, and avoiding
generic AI-generated UI patterns.

[View skill →](skills/professional-frontend-design/SKILL.md)

## Philosophy

These skills are intentionally opinionated.

They are not intended to force every project into the same design or
development pattern.

Instead, they provide principles that help AI make better decisions while
adapting to the purpose, users, and identity of each project.

For frontend design, the primary goal is not to make an interface look
"modern" simply because a certain style is popular.

The goal is to create something that feels intentionally designed.

> Better composition over unnecessary decoration.
>
> Better interaction over unnecessary animation.
>
> Better hierarchy over unnecessary components.
